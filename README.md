# Coin Quest

Build a modern, aesthetic, Gen-Z-focused financial literacy web platform that teaches users about personal finance through interactive, realistic scenarios and consequences, rather than traditional textbook-style financial education.

The platform should feel like a fun, personalized financial experience, not a boring banking website or an educational portal.

CORE CONCEPT

The key learning philosophy is:

Scenario → Decision → Consequence → Concept → Feedback → Personalized Next Scenario → Improvement

Users should first EXPERIENCE a financial situation, make a decision, see the consequences of that decision, and THEN learn the financial concept behind it.

For example:

A user receives a scenario:

“You just received ₹25,000. You have rent, food, subscriptions and an upcoming emergency expense. What will you do with your money?”

The user chooses an option.

The platform then shows the simulated financial consequence of that decision.

Example:

“You spent too much on discretionary expenses. You now have only ₹2,000 left before your next income.”

Then explain:

What did you learn?
This scenario demonstrates the importance of budgeting, emergency funds and prioritizing needs over wants.

The platform should then recommend another scenario based on the user's previous decision.

7. PERSONALIZED LEARNING

The platform should remember the user's decisions.

Based on their choices, dynamically recommend future scenarios.

Example:

If the user repeatedly overspends:

“You seem to struggle with balancing wants and needs. Want to try a budgeting challenge?”

If the user takes excessive investment risk:

“You’re comfortable with risk 👀 Let's test how well you understand it.”

If the user saves consistently:

“You're building a strong saving habit. Ready to explore investing?”

Make personalization one of the core differentiators of the platform.

MOST IMPORTANT PRODUCT PRINCIPLE

Do NOT make this a website that simply says:

“Here are 20 financial concepts. Read them.”

Instead make it:

“Here's a situation. What would YOU do?”

Then:

“Here's what happened because of your choice.”

Then:

“Here's the financial concept behind it.”

Then:

“Now let's see if you can handle the next situation.”

The user should feel like they are learning finance by living through decisions.

PROTOTYPE PRIORITY

Since this is a prototype, prioritize quality over building every possible feature.

The most polished flow should be:

Landing → Onboarding → Dashboard → Scenario → Decision → Consequence → Concept → Personalized Next Scenario

Make these screens highly polished and fully clickable.

Use mock data wherever necessary.

Create realistic Indian financial scenarios using ₹ (INR) rather than dollars.

Keep language conversational, friendly and Gen-Z appropriate while still being credible and educational.
